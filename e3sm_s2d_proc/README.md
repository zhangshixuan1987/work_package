# e3sm_s2d_proc

Scripts for the E3SM v3 seasonal-to-decadal (S2D) ensemble hindcast workflow
on NERSC Perlmutter (`pm-cpu`): build atmospheric initial conditions, generate
ensemble initial states, run bundled multi-member hindcasts, and post-process
the output.

The working copy lives in `~/e3sm_project/run_test_s2d`. This directory keeps
one canonical version of each hand-written script; per-year working copies,
per-member scripts generated under `scripts/`, Slurm logs, and backups are not
tracked.

Model configuration throughout is `WCYCL20TR` at `ne30pg2_r05_IcoswISC30E3r5`.
Paths, accounts (`#SBATCH --account`), case names, and date ranges are
experiment-specific; review them before submitting.

## Workflow

| Step | Directory | Purpose |
| --- | --- | --- |
| 1 | `atm_init/` | Pre-stage ERA5 and interpolate it to EAM ne30np4 L80 initial conditions with BetaCast `atm_to_cam`. |
| 2 | `ensemble_generation/` | Two candidate atmospheric ensemble-perturbation methods for S2D experiments: DART-generated perturbations (`dart_perturb/`) and DART-ensemble anomalies added to a reference state (`custom_perturb/`); see its README. |
| 3 | `ensemble_init/` | Coupled ensemble initial conditions for three sets (JRA55-FOSIRL, brute-force CFSR, 4DEnVarOcn), with DART-perturbed atmospheric members; see its README. |
| - | `ensemble_pert_analysis/` | Check perturbed EAM initial conditions against the base state: EN00 bit-for-bit check, perturbation statistics, distribution and vertical-spread plots. Independent of the perturbation method. |
| 4 | `hindcast_run/` | Bundled ensemble hindcast driver (compile once, set up all lead dates x members, run them concurrently in one Slurm allocation), with a sample run workflow for each initial-condition set; see its README. |
| 5 | `postprocess/` | Per-set archive/transfer stages (st_archive, zstash to HPSS, move to CFS, check and clean) and ncclimo/ncremap time series and climatologies for atmosphere, land, river, ocean, and sea ice; see its README. |
| 6 | `diagnostic/` | RTENSO2026 2015/16 El Nino case-study notebooks (Nino plumes, anomaly maps and pattern ACC, land/sea-ice IC sensitivity, teleconnections), following the ESP-Lab suite with Reanalysis lead-time climatologies for drift correction; see its README. |
| - | `control_runs/` | Standalone `run_e3sm` control cases used to test the S2D configuration. |

### Initial-condition methods

`ensemble_init/` holds three established initial-condition sets and the new
`Reanalysis/` set, each a self-contained working directory driven by its own
`submit_all_year.bash`, plus one set in preparation:

- `JRA55_FOSIRL/`: ocean, sea-ice, land, river, and coupler state from the
  matching JRA55-forced (FOSI) restart.
- `BruteForce/luke_cfsr/`: same restart, with the MPAS-Ocean state replaced by
  Luke Van Roekel's CFSRv2 analysis (`BruteForce/ben_kirtman/` is the earlier
  brute-force generator).
- `Reanalysis/`: same restart, with the MPAS-Ocean state replaced by Luke Van
  Roekel's calendar-date CFSR ocean ICs (`mpas_<YYYYMMDD>.cfsr.ic.nc`; 2015 and
  2026 so far). On hold until the full input data are ready.
- `4DEnVarOcn/`: all components from the 4DEnVar coupled assimilation
  (May, 1980-1995); `4DEnVarOcn.AnomalyDA/` keeps the earlier anomaly-assimilation
  setup (May/November, 1980-2015) as a record.
- `RTENSO2026/` (in preparation): 2026 hindcast initial conditions for
  Feb/May/Aug/Nov 01. ERA5 atmosphere and CFSR ocean as in the brute-force set
  (prepared by collaborators); sea-ice, land, and river restarts from a
  BruteForce year closest to the same-date climatology (`clim`) or to the ERA5
  anomaly (`obs`), and the DART
  20-member atmospheric ensemble, are prepared here. The same 2015 dates test
  the sensitivity against the actual 2015 BruteForce ICs.

In the three established sets, the atmospheric ensemble members are generated by running DART's
`perturb_single_instance` (EAM-SE) on the base EAM initial condition; `EN00`
stays unperturbed. See `ensemble_init/README.md`.

The hindcast driver selects the matching source with `my_leadref` and
`my_refcase1`/`my_refcase2` in `create_and_setup_case.sh`; `hindcast_run/` has a
sample run workflow for each set (`4DEnVarOcn.AnomalyDA/`, `BruteForce/`, `JRA55_FOSIRL/`, `RTENSO2026/`).

### Spin-up

`hindcast_run/spinup/` runs a short one-month spin-up bundle before the main
hindcast. `run_spinup_bundle.sh` sources `create_and_setup_case.sh` from the
working directory, so run it alongside the hindcast configuration.
