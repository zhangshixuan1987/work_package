# Ensemble perturbation methods

Two candidate methods for generating atmospheric ensemble perturbations for
potential S2D experiments. Both start from a single reference EAM initial
state (`eam.i`) and produce perturbed members; they differ in where the
perturbations come from.

| | `dart_perturb/` | `custom_perturb/` |
| --- | --- | --- |
| Perturbation source | Generated by DART from the reference state itself | Centered anomalies from an existing 40-member E3SM-DART assimilation ensemble |
| Character | Random perturbations, not tied to the flow of the day | Flow-dependent, sampled from DART analysis spread |
| Variables | Set in DART `eam_pert_input.nml` (temperature) | `T`, `U`, `V`, `Q`, `PS` |
| Members | `my_ensnum` | 20 (`EN01` control + 19 perturbed) |
| Tooling | Bash + DART `filter` on Perlmutter | Python notebooks (xarray) |

## Method 1: DART-generated perturbations (`dart_perturb/`)

DART's `filter` runs with `perturb_from_single_instance = .true.` and no
assimilation cycles: it copies the reference `eam.i` to every member and adds
perturbations as configured in `${my_dart_code}/models/eam-se/work/eam_pert_input.nml`.
The perturbed members are then meant to be spun up by a short model
integration before use.

| Script | Purpose |
| --- | --- |
| `create_and_setup_case.sh` | Configuration: date, ensemble size, reference IC, DART code and run layout. |
| `1_run_e3sm_ensemble_setup.sh` | Create and build the E3SM case. |
| `2_run_dart_e3sm_icbc.sh` | Stage initial and restart files (EAM, ELM, MOSART, MPAS-Ocean, MPAS-Seaice, coupler) and `rpointer` files for a DART run. |
| `run_dart_eam_perturb.sh` | Generate the perturbed members with DART `filter`. |
| `eam_dart_assimilation.sh` | Single-cycle EAM-DART assimilation with 6-hourly `obs_seq` observations (NCEP+ACARS+GPS+AIRS). |

The `ensemble_init/` generators use the same idea for the current S2D initial
conditions, but call DART's `perturb_single_instance` instead of `filter`.

## Method 2: DART-ensemble anomalies on a reference state (`custom_perturb/`)

Uses an existing 40-member E3SM-DART ensemble (EAM `eam.i` and ELM restarts
for `EN01`-`EN40`) as a library of analysis perturbations.

1. `select_dart_20_member_subset.ipynb` picks a 20-member subset that best
   preserves the full ensemble's mean and spread (configurable mean, spread,
   and covariance weights) across sampled EAM and ELM features. It uses a
   fixed-seed random search (`N_TRIALS`) followed by one-member swaps, and
   writes `selected_20_members.csv`. The same member IDs apply to the paired
   atmosphere and land states. Validate the subset at more than one date
   before using it for a campaign.
2. `add_dart_perturbations_to_hyb_clim.ipynb` adds the subset's centered
   anomalies to a reference state (`HYB` or `FREE_CLIM`) for each configured
   date (December 2011 and May 2012 sets):

   ```text
   dA_i      = A_DART,i - mean(A_DART, subset)
   A_out,i+1 = A_reference + ALPHA * dA_i,   i = 1..19
   ```

   `EN01` is the unperturbed reference. The 20th selected member contributes
   to the mean but is not used as a perturbation, so the output mean is offset
   from the reference by `-ALPHA * dA_omitted / 20`; validation checks this.
   `Q` is clipped at `Q_MIN`, all fields are checked against physical limits,
   and non-atmosphere restart files are linked or copied from the reference.

`util/dart_subset_selection.py` holds the subset-selection helpers. Data paths
in both notebooks are set in their configuration cells.
